Módulos con frontera de microservicio
Exonero es una plataforma web con tres componentes principales: el frontend, el backend y la base de datos. [→] El frontend está hecho con React y Vite. Las pantallas nunca llaman al servidor directamente: usan una función por endpoint, en la carpeta api, y todas pasan por un único cliente que agrega el token. Para los mapas usamos Leaflet. [→] El backend es una API en FastAPI y Python, dividida en diez módulos: cuentas, perfiles, catálogos, búsqueda, agenda, clases, pagos, mensajería, reseñas y privacidad. El frontend le habla por HTTP, con JSON, y cada pedido lleva un token JWT que dice quién es el usuario y qué rol tiene. [→] Toda la información se guarda en una base de datos relacional PostgreSQL, que corre en Docker: 25 tablas, y los cambios de estructura los manejamos con migraciones de Alembic. [→] Los módulos tienen frontera de microservicio: ninguno lee las tablas de otro, se comunican a través de su lógica. Así, cualquiera se podría separar como un servicio aparte.

Cuatro partes, cada una de punta a punta: del backend a las pantallas
Y esto mismo se repite en todo el proyecto. Los diez módulos tienen los mismos cuatro archivos: rutas, esquemas, lógica y modelos; y del lado del frontend, cada uno tiene su archivo en la carpeta api. [→] Nos repartimos el trabajo en cuatro partes, y cada una iba de punta a punta: del backend a las pantallas. Como todo sigue el mismo patrón, cualquiera de nosotros puede leer el módulo de otro.
Modelo de negocio

B2C · 10 % de comisión por reserva

El estudiante reservaEl pago queda retenido
El profe confirma la claseAsí aprueba el pagoSi la rechaza, el pago se libera
Se cobra la reserva10 % para Exonero
Ya que el problema es entre particulares, nos pareció razonable que el modelo de negocio sea con clientes finales, B2C: Exonero cobra un 10 % de comisión por cada reserva. [→] Cuando el estudiante reserva, paga con su tarjeta y el pago queda retenido. [→] El profesor tiene que confirmar la clase: al confirmarla, aprueba el pago; si la rechaza, el pago se libera y al estudiante no se le cobra nada. [→] Recién ahí se cobra la reserva, y Exonero se queda con el 10 % de comisión. (Hoy este flujo funciona con un cobro simulado.)
